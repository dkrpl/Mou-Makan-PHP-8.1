###################
Aplikasi POS RESTO
###################

Point Of Sales (POS) adalah tempat kasir (check-out counter) dengan mesin kasir (Cash Register). Sesuai dengan namanya, POS merupakan titik penjualan (Check-out) tempat di mana transaksi selesai.

- Administrasi User Kasir
- Administrasi Laporan Penjualan


*******************
Server Requirements
*******************

PHP version 5.4 or newer is recommended.

It should work on 5.2.4 as well, but we strongly advise you NOT to run
such old versions of PHP, because of potential security and performance
issues, as well as missing features.
